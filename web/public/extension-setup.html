JobLume Autofill extension

The extension fills the standard fields of employer application forms (Greenhouse, Lever, Ashby and Workable) from your JobLume details. It never submits anything: you review every answer and press Submit yourself.

Install it (Chrome, Edge or Brave on a computer)

  1. Ask whoever runs your JobLume for the extension/dist folder, or build it: in the JobLume folder run npm run build -w joblume-extension.
  2. Open chrome://extensions in the browser and switch on Developer mode (top right).
  3. Press Load unpacked and choose the extension/dist folder.
  4. Come back to JobLume and reload this page. Open an application: a Fill the form with the JobLume extension button appears.

Fill in Settings, Contact details for application forms first so there is something to fill.

Full guide: docs/extension-setup.md in the JobLume project.
