# Talent platforms: join once

These are places where remote companies hire pre-vetted people. You sign up once, pass their screening, and they bring roles to you. Open the page, create a profile, and keep it up to date.

| Platform | What it is | Where to join |
| --- | --- | --- |
| Remotebase | Matches vetted developers with remote companies on long-term contracts. | https://remotebase.com/ |
| Index.dev | A vetted network of developers placed with US and EU companies. | https://www.index.dev/ |
| Somewhere | Remote staffing for engineers and other tech roles, with a screening process. | https://somewhere.com/ |
| Working Nomads | A remote job board. Its listings are also scanned by JobLume, but a free profile there is still worth having. | https://www.workingnomads.com/jobs |
| Turing | Vets developers and places them on long-term remote roles with US companies. | https://work.turing.com/ |
| Andela | Places experienced technologists with global companies, with a talent network you apply to. | https://www.andela.com/for-talent |

Toptal and Upstack are two more of the same kind (a screened freelance network and a tech staffing firm). Their sites block automated checks, so no link is given here: search for each by name and use the "apply as talent" option on its own site. Remote.co is a job board that could not be reached when this list was written, so it is left out.

## What these are, honestly

These are marketplaces you apply to once. They are not listings that JobLume can scan, and JobLume cannot apply for you there: each one has its own sign-up form and screening (tests, interviews, sometimes a trial task) that only you can complete. Joining is a slower, one-time effort that can bring a steady flow of roles later, so it works alongside the daily matches JobLume finds, not instead of them.
